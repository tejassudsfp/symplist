# Security policy

Symplist is pre-release and has no supported deployed application versions in this repository. Security-sensitive design and future implementation changes are still welcome.

Do not disclose vulnerabilities, credentials, private artifacts, or exploit details in a public issue. Use GitHub's private reporting entry point at https://github.com/tejassudsfp/symplist/security/advisories/new when available. If private reporting is unavailable, open an issue containing only a request for a private contact channel, without vulnerability details or sensitive data.

Include the affected revision, reproduction steps using synthetic data, impact, and suggested mitigation. Test only systems you own or are authorized to assess. Do not access other users' content, send unsolicited emails, or run destructive testing.

The maintainer will investigate and coordinate disclosure; no response-time guarantee or bounty program is currently offered. Do not treat a prototype or specification as a security-audited product.
