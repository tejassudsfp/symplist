# Task handoff mode

Read [overall.md](overall.md), [themes.md](themes.md), and [handoff and sharing requirements](../../docs/notes/files/16_simon_handoffs_and_artifact_sharing.md). Derive visual treatment from the supplied UI sample.

## Surface and flow

Design a task-associated sheet/page entered through the task menu, palette, or Simon suggestion. Choose destination (a coding assistant, a general-purpose assistant, Other), outcome, source artifact/revision/section selection, and editable generated prompt. Target names are handoff labels, not connected launch buttons. Show objective, constraints, context inventory, expected output, acceptance checks, open questions, and return instructions.

## Required states

Cover manual draft, Simon reading bounded sections, generating, incomplete context, edited prompt, stale source before release, preview/release, copying full prompt with links, download, expired link/replacement, and return-result guidance. Separate draft generation from creating access. Show full instructions without stuffing every source document into the prompt. Link/password compatibility and expiry are concise. No automatic external sends or heavy-work execution. Mobile uses a full surface; keyboard focus preserves the task draft.

## Handoff to implementation

Provide desktop and mobile frames, accessible controls, focus/escape behavior, success and failure transitions, and preserved task context. Apply independent style/accent/brightness tokens. Use fictional content and nonfunctional links; annotate authorization and persistence boundaries. Include a keyboard-only prototype from task to this surface and back.
