# Roadmap

Everything below is pending implementation. This order groups work; it does not remove any requirement from the full specification or promise a delivery date.

1. Foundation: Next.js/Nest setup, direct D1/R2 contracts, encryption, OTP, explicit beta admission, administrator bootstrap.
2. Workspace: tasks/subtasks, page/chat layout, all themes with independent accents, responsive and keyboard interactions.
3. Documents: actual Git publication/recovery, section tools, history/restore, encrypted search.
4. Simon: bounded facilitation, Composio wrappers, scoped incoming MCP, approvals, Nest/Trigger parity and reconnects.
5. Sharing: specialist handoffs, artifact snapshots, reviewed grants, password/public variants, standalone read-only views.
6. Time: deadlines, calendar, quiet hours, notifications, Resend reminders, durable/local job recovery.
7. Release readiness: Vault/recovery, remaining administrative and failure states, optional PostHog analytics, privacy checks, accessibility, clean self-hosting, backup/restore, and deployment guides.

Acceptance is defined in [the numbered notes](docs/notes/files/00_index.md), [44 screen briefs](design/mockups/overall.md). No public release is complete until implementation, tests, and documented setup support the claims made in the README.
